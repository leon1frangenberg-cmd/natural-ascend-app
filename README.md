# Natural Ascend — Jacked German (test)

A mobile web prototype of the Natural Ascend Skool classroom, so Leon can test it on a phone.

Open the GitHub Pages site on your phone. **Open Jacked German** opens the Claude artifact in a new tab (you may need to be signed in to Claude).

Use **Member view / Admin view** at the top, or the ⋯ menu, to show or hide the Members list (admin only).

This repo contains only the public prototype (no prices, no private client data).
